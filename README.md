# kohei321dev GitHub defaults

このリポジトリは、`kohei321dev`アカウント配下のリポジトリで共通利用するIssue Form、Pull Requestテンプレート、Contribution、Security、Support方針を管理します。

## 適用範囲

- 対象リポジトリに同種のファイルがない場合、GitHubのdefault community health fileとして利用されます。
- 対象リポジトリに独自の`.github/ISSUE_TEMPLATE/`または`config.yml`がある場合、そのリポジトリ側の定義が優先されます。
- プロダクト固有の要求、仕様、設計、運用手順は各リポジトリの`docs/`で管理します。

## 公開安全性

このリポジトリはPublicです。secret、token、private URL、個人情報、顧客情報、非公開リポジトリ固有の情報、raw logを保存しません。

## 関連テンプレート

新規プロダクトリポジトリのファイル構成は、`kohei321dev/product-repository-template`で管理します。Issue・Pull Requestテンプレートは本リポジトリから継承させるため、原則としてプロダクトテンプレート側へ複製しません。
